# Hover Tank Arena

**公開URL：https://hovertank-arena.lildayne.workers.dev**

最大4人で遊べる、軽量な3Dホバー戦車のブラウザ対戦ゲームです。三人称視点で、滑る・撃つ・跳ぶ操作の気持ちよさを優先しています。PC（キーボード＋マウス）とスマートフォン（タッチ、横画面）に対応しています。

- クライアント：[PlayCanvas Engine](https://developer.playcanvas.com/user-manual/engine/) 2.23（Editor は不使用、Vite でビルド）
- 対戦サーバー：Cloudflare Workers + Durable Objects（1部屋＝1つの Durable Object、サーバー権威型）
- 公開：Cloudflare の無料プラン。画面のファイルと WebSocket を同じURLから配信（HTTPS／WSS）

当初は Colyseus を候補にしていましたが、カード登録なしで使える無料のサーバーとして Cloudflare を選んだため、対戦サーバーは Durable Objects で実装しています（Colyseus は Cloudflare 上では動きません）。ゲームのルール（移動・砲弾・命中・試合進行）は `shared/` にあり、通信部分とは分けてあります。

## 遊び方

- **クイックマッチ**：「クイックマッチ」を押すと、空きのある公開ルームに自動で入ります（人数の多い部屋から順に埋め、空きがなければ新しい部屋を作る）。希望は「どちらでも／個人戦／チーム戦」。公開ルームのルールは5分間で固定です。入った後でも「招待」ボタンで友達を同じ部屋に呼べます。
- **友達と遊ぶ（招待URLの部屋）**：

1. 公開URLを開き、ルール（下記）を選んで「部屋を作る」を押す。この部屋はクイックマッチには出てきません
2. 表示された招待URL（`?r=部屋コード`）を相手に送る。相手は開いて「この部屋に参加」を押す
3. 勝敗がつくと結果を10秒表示し、同じルールで次の試合が自動で始まる

**ルール**（部屋を作るときに選択。試合中も ⚙ →「このルールでニューゲーム」で変更できます）

| | 内容 |
|---|---|
| 個人戦 | 全員が敵。撃破数を競う |
| チーム戦 | 赤チーム・青チームの2チーム（参加順に交互に振り分け、⚙ の「チームを変える」で移動可）。味方の弾は当たらずすり抜け、チームの撃破数の合計を競う。チームごとにステージの西側・東側からスタート |
| 5分間 | 5分経った時点で撃破数が多いほうの勝ち（同数は引き分け） |
| N キル先取 | 5・10・15・20 から選択。先に到達した人（チーム）の勝ち。決着がつかない場合は15分で終了 |

| 操作 | PC | スマホ（横画面） |
|---|---|---|
| 移動 | WASD／矢印キー（画面の向きが基準） | 左半分をドラッグ（その場に出る仮想スティック） |
| 照準 | マウス（画面クリックでマウスを固定、Escで解除） | 右半分をドラッグ。FIREボタンも押したままドラッグで照準できる |
| 射撃 | 左クリック（押しっぱなしで連射）／F | FIRE |
| ジャンプ | Space | JUMP |
| ドリフト | Shift／右クリック（押している間） | DRIFT（押している間） |

照準は画面中央の十字に合わせるだけで、砲弾の落下も自動で補正して砲身の角度が決まります。

- **ドリフト・ターボ**：ドリフトを押したまま横滑りするとゲージが溜まり、離すと車体の向きへ加速します（約0.55秒で青＝最高時速23m/s、約1.3秒でオレンジ＝27m/s。通常は17m/s）。横向きの勢いも前に向け直されるので、曲がり角での方向転換や、撃たれたときの回避に使えます。ゲージは照準の下に出ます。
- **ステージ**：約80m四方の闘技場。砲弾は秒速70m。
- **遮蔽物**：中央に丸い丘（高さ2.6m・直径30m、どの方向からでも登れる）と、各スポーンの前に壁が1枚ずつ（計8枚）。砲弾も遮るので、隠れながら撃ち合えます。名前表示も遮蔽物の向こうでは消えます。
- **回復アイテム**：試合開始から40秒後に中央の丘の頂上に出現し、取るとHPが全回復します。取られてから40秒後に次が出ます（HPが満タンの戦車は取れないので、必要な人のために残ります）。画面上部に出現までの秒数を表示します。
- **ニューゲーム**：⚙（設定）の「ニューゲーム」を2回押すと、部屋の全員のスコア・タイマー・位置をリセットして最初からやり直せます。試合終了画面の「すぐに次の試合へ」でも同じです。
- **リスポーン直後の無敵**：2秒間シールドが付きますが、**自分が撃つとその場で解除**されます（無敵のまま一方的に攻撃できないようにするため）。

## CPU（コンピューター対戦相手）

- **クイックマッチ**：「人数」で 2人（1対1）・3人・4人 から選びます（チーム戦は常に2対2）。同じモード・同じ人数を選んだ人どうしでマッチングし、足りない席はCPUが埋めるので1人でも遊べます。
  - **途中参加なし**：新しい部屋は最初の5秒だけ「対戦相手を探しています」で人を待ち（その間は自由に走れる・撃てない）、5秒たつか満席になると空き席をCPUで埋めて試合開始。試合中はクイックマッチから人が入らず、抜けた人の席もそのまま。試合の合間（結果画面の10秒）だけ新しい人を受け付け、次の試合からCPUと入れ替わります。招待URLで呼んだ友達だけは試合中でも入れます。
  - クイックマッチのCPUは名前に「CPU」と付かず、普通のプレイヤー名とレベルで表示されます。ロビーにもCPUが入ることや同時接続数は表示していません（人が少ないうちは過疎に見えるため。`/api/stats` で人数は取得可能）。
  - **強さは部屋にいる人のレベルの平均に合わせて自動で決まります**（Lv.1 ≒ よわい、Lv.30前後 ≒ ふつう、Lv.50 ≒ つよい。1体ごとに少しばらつきあり）。表示されるレベルも平均±3、見た目もそのレベルで解放できるアイテムだけを使います。強さの設定はありません。
- **プライベートマッチ（招待URLの部屋）**：ルールの「CPU」で 0〜3体、「CPUの強さ」で よわい／ふつう／つよい を選べます（試合中も ⚙ のルールから変更可）。こちらのCPUは名前の横に「CPU」と表示されます。人が増えて満席になるとCPUが抜けます。
- CPUはサーバー上で動き、**人と同じルール**（同じ速度・同じ弾・同じ連射間隔）で入力を出しているだけなので、ずるはしません。照準のブレ・反応の遅さ・砲塔を回す速さ・撃つ積極性・先読みの正確さで強さが変わります（よわい〜つよいの間は連続的に変化）。
  - 敵を探す（見えている・近い・HPが低い相手を優先）、見えなくなったら最後に見た場所へ向かう
  - 好みの距離を保って横に回り込みながら撃つ、壁を避けて進む、詰まったら下がってジャンプ
  - HPが減ると回復アイテムを取りに丘へ、ふつう以上はドリフトターボを使い、飛んでくる弾をジャンプでよける
  - CPU同士の試合での命中率の目安：よわい 約27%、ふつう 約35%、つよい 約60%
- CPUを倒しても経験値・ミッションは進みます。

## 撃破の演出（ヒットストップ）

- 自分が敵を倒した瞬間は約0.12秒、自分がやられた瞬間は約0.18秒、画面の中の時間が止まります（戦車・カメラ・エフェクト）。そのあいだ画面は揺れ、音はこもって重低音が鳴り、止まったあとは滑らかに追いつきます。止まるのは見た目だけで、操作の受け付けとサーバーの計算は止まらないので、ずれたり不利になったりしません。
- 撃破の爆発は段階的：白い閃光と周りを照らす光 → 転がる火球 → 地面を走る衝撃波リング2枚と光の柱 → 火花の噴水 → 煙を引いて飛ぶ破片と、やられた戦車の色で吹き飛ぶ砲塔 → 周りで続く小爆発3回 → 立ちのぼる黒煙と火の粉 → 地面の焦げ跡（6秒）。撃破演出（プラズマ・花火・紙吹雪・黒炎）ごとに色と追加演出が変わります。
- 画質「低」では光の演出を省き、粒の数も減らします。

## サウンド

効果音とBGMはすべてブラウザ内で合成しています（音声ファイルのダウンロードなし、Web Audio API）。

- 砲撃（重低音の衝撃＋破裂音＋残響）、着弾の爆発、命中の金属音、被弾、撃破（大爆発＋自分が倒したときはファンファーレ）、やられたとき、シールド、ジャンプ・着地、ドリフトのスキール音（溜まるほど高くなる）と青／オレンジに溜まった合図、ターボの噴射音、エンジン音（速度で音程と明るさが変わる）、回復アイテム出現・取得、リスポーン、試合開始の号令、勝ち／負けのジングル、レベルアップのファンファーレ、ボタン音
- 他の戦車の音は距離で小さくなり、カメラから見た左右に振り分けます。
- BGM：ロビーは落ち着いた曲、試合中はドラムとベースの効いた曲、5分間の試合の残り30秒はテンポが上がって激しくなります。
- ⚙ で BGM・効果音の音量を別々に調整、🔊 ボタンでミュート（ロビー右上・試合中は右上）。スマホは最初に画面に触れたときに音が出始めます（ブラウザの仕様）。iPhone はマナーモードだと鳴らないことがあります。

## レベルと見た目のカスタマイズ（強さは変わらない）

試合を終えると経験値が入り、レベルが上がります（最大Lv.50）。**レベルや報酬は見た目だけで、移動速度・攻撃力・当たり判定などは全員同じ**です（当たり判定は見た目の部品に関係なく固定）。

- **経験値**：参加するだけで基礎経験値（1分あたり20、最大5分で100）。撃破15・命中2・勝利60（個人戦で3人以上の2位は25、引き分け20）・ドリフトターボ・回復アイテム取得にも少し入ります。1日の最初の試合は+100、最初の勝利は+150。ほとんど動かず撃ちもしなかった試合（40m未満の移動かつ射撃2発以下）は対象外です。
- **レベルの上がり方**：レベルが上がるほど次に必要な経験値が増えます（Lv.1→2は150、Lv.10→11は470、Lv.49→50は4110、Lv.50まで合計82,400）。目安：Lv.5まで約4試合、Lv.10まで約11試合、デイリーミッション込みで1日6試合なら約1か月でLv.50。
- **レベル報酬**：5レベルごとに小さな報酬（塗装・柄・軌跡色など2〜3個）、10レベルごとに大きな報酬（砲塔・エアロパーツ・撃破演出・エンブレム・名札の枠・称号など4〜8個）。一覧はロビーの「ミッション」→「レベル報酬」。
- **ガレージ**（ロビー、または試合中の ⚙ →「ガレージ」）で着せ替え。右側に自分の戦車がプレビューされます。全12種類・101アイテム：
  - 塗装（15色）、柄（ストライプ・砂漠迷彩・タイガー・デジタル迷彩・ファイヤー・カーボン・チェッカー・ハザード）
  - 砲塔（標準・ツインバレル・ロングバレル・ヘビーキャノン・レールガン・キングス・ドーム・ミサイルポッド）
  - リアパーツ（スポイラー・ツインフィン・ジェットウイング・フラッグアンテナ・ツインマフラー）、サイド／フロント（サイドスカート・フロントブレード・サイドポッド・カナード）
  - ホバーの光の色、弾の軌跡の色、ドリフト火花の色（青・オレンジのターボ段階の色は情報なので変わりません）、自分が撃破したときの演出（プラズマ・花火・紙吹雪・黒炎）
  - エンブレム・名札の枠・称号（名前の横・上に表示され、ほかのプレイヤーにも見えます）
- **敵味方の見分け**：車体の色が自由になったので、**敵の戦車は赤、味方の戦車は青の輪郭線**で囲みます（自分の戦車は輪郭なし）。輪郭は遠くでも同じくらいの太さに見えるよう、距離に応じて太くなります。
- **デイリーミッション**：毎日0時（日本時間）に3つ（かんたん150・ふつう250・むずかしい400 XP）。3つとも達成で+300。1日1回だけ1つを入れ替えられます。
- **長期ミッション（称号）**：20種類。達成すると称号と経験値、一部は限定アイテム（例：「撃墜王」1000撃破でドーム砲塔、「ドリフト職人」ターボ300回でレインボー火花）。
- **データの保存**：アカウント登録なし。初回起動時にサーバーが匿名のIDを発行し、この端末（ブラウザ）に保存します。経験値・ミッション・解放状況は**サーバーが試合結果から計算**して保存するため、端末側で書き換えることはできません。
- **引き継ぎ**：ロビーの「引き継ぎ」で8文字のコード（24時間有効・1回限り）を発行し、別の端末で入力すると同じデータを使えます（機種変更や、iPhoneのSafariとホーム画面版の両方で遊ぶとき）。

## プレイ統計（開発者用ページ）

`/admin.html` で、1日ごと（日本時間）の数字を見られます。管理用の鍵を入力したブラウザだけが見られ、鍵はそのブラウザに保存されます。

- いま遊んでいる人数と部屋数、今日の「開いた人」「遊んだ人」「はじめて遊んだ人」「試合数」「プレイ時間」「同時接続ピーク」（昨日との差つき）
- 日別の人数・試合数・プレイ時間のグラフ（7日／30日／90日）、レベル分布、試合の内訳（クイックマッチの人数別・チーム戦・プライベート、CPUが占めた席の割合）、日別の数字の表
- 記録するのは匿名のプロフィールID（端末に保存したIDのハッシュ）だけで、名前やIPアドレスは保存しません。集計はサーバー（Durable Object `GameStats`）が試合結果とプロフィールの読み込みから行います。
- 鍵そのものはどこにも保存しておらず、設定（`wrangler.jsonc` の `ADMIN_KEY_HASH`）にはそのSHA-256だけを書いています。鍵を変えるときは、新しい鍵のSHA-256（`echo -n '新しい鍵' | sha256sum`）をそこに書いてデプロイします。
- 集計は機能を入れた日（2026年10月28日）からで、それより前の数字はありません。

## アプリとして使う（PWA）

ブラウザのメニューから「ホーム画面に追加」すると、アドレスバーのない全画面のアプリとして起動できます（ストア経由のインストールは不要）。

- **Android（Chrome / Edge）・PC（Chrome / Edge）**：ロビーに「ホーム画面に追加」ボタンが出ます。押すとブラウザのインストール確認が開きます。起動すると全画面・横向きになります。
- **iPhone / iPad（Safari）**：iOS にはボタンからインストールさせる仕組みがないため、ボタンを押すと「共有ボタン →『ホーム画面に追加』」の手順を表示します。iOS では横向きの固定はできません（縦向きのときは「横向きにしてください」と表示）。
- **2回目以降の起動が速い**：Service Worker が画面・プログラム・3Dモデル・アイコン（計約400KB）を端末に保存し、次回からはネットに取りに行かずに表示します。ページ本体だけは毎回ネットを優先して取りに行くので、更新は次の起動で反映されます。古い保存分は更新時に自動で消えます。
- **オフライン時**：ロビーとステージは表示されますが、対戦はできません（「オフラインです」と表示し、対戦ボタンを無効にします）。`/api`（部屋・マッチング・WebSocket）は保存も横取りもしません。
- 招待URLはアプリではなくブラウザで開きます（そのまま遊べます）。
- アイコンは `tools/render_icon.py`（Blender で戦車を描画）と `tools/make_icons.py`（背景と合成し、各サイズを書き出し）で作り直せます。

## ローカルでの起動

Node.js 20 以上が必要です（22 で確認）。

```bash
npm install
npm run dev        # ビルドしてから wrangler dev を起動 → http://localhost:8787
```

`wrangler dev` は Cloudflare と同じ実行環境（workerd）を手元で動かすので、Durable Objects も含めてそのまま試せます。Cloudflare のアカウントは不要です。
同じLANのスマホから試すときは `npx wrangler dev --ip 0.0.0.0` で起動し、`http://<PCのIP>:8787` を開きます。

## デプロイ（Cloudflare）

設定はすべて `wrangler.jsonc` にあります。

**GitHub 連携（設定済み）**：Cloudflare の Workers Builds がこのリポジトリにつながっていて、`main` に push すると自動でビルド（`npm run build`）とデプロイ（`npx wrangler deploy`）が行われます。新しく作り直す場合は、Cloudflare ダッシュボードの「Workers & Pages」→「Create application」→「Continue with GitHub」でこのリポジトリを選び、同じコマンドを指定します。

**手元から**：`npx wrangler login` のあと `npm run deploy`。

無料プランの目安（Durable Objects）：リクエストは1日10万件まで。受信する WebSocket メッセージは20件で1件と数えるので、入力を2ティック分まとめて送るこのゲームでは、4人対戦で1日あたり約9時間が目安です。送信メッセージは課金対象外です。上限に達するとその日は部屋に接続できなくなります（課金はされません）。

## 構成

```
client/   画面（PlayCanvas）。main.js＝描画・予測・補間・HUD、audio.js＝効果音とBGMの合成、looks.js＝見た目（部品の組み立て・柄・輪郭線シェーダー）、profile.js＝レベルAPI、progress-ui.js＝ガレージ・ミッション・経験値表示、input.js＝キーボード／マウス／タッチ、net.js＝通信、fx.js＝エフェクト、stage.js＝遮蔽物の見た目、pwa.js＝インストールボタンとオフライン表示、sw-template.js＝Service Worker の元（ビルド時に保存ファイル一覧を埋め込んで dist/sw.js を生成）
worker/   Cloudflare Worker（index.js＝静的ファイル配信と部屋の振り分け、/api/profile）と Durable Object（room.js＝接続・席・30Hzループ、matchmaker.js＝クイックマッチ用の公開ルーム一覧、profile.js＝プレイヤーごとのレベル保存と引き継ぎコード）
shared/   クライアントとサーバーで共通のコード。bot.js＝CPUの思考、sim.js＝移動・砲弾・ドリフト・弾道計算、game.js＝試合ルールと試合ごとの成績集計、arena.js＝スポーン位置と遮蔽物の配置、progress.js＝レベル曲線・アイテム・ミッション・経験値の計算式
public/   配信する素材（GLB、当たり判定用の高さマップ）とクレジットページ
tools/    元の .blend から素材を作り直すスクリプト（Blender の Python モジュール bpy を使用）
test/     自動テスト
```

### 通信のしくみ

- 部屋ごとに1つの Durable Object がゲームを毎秒30回計算し、毎秒30回スナップショットを全員に送ります。
- クライアントは入力（移動方向・照準・射撃・ジャンプ・ドリフト）だけを送ります。位置はサーバーが入力から計算するので、クライアントが位置を偽ることはできません。入力は実時間を超える速さでは処理しない（速度改造の防止）、値の範囲も検証しています。
- 自分の戦車はクライアント側で先に動かし（予測）、サーバーの結果が届いたら、まだ処理されていない入力を再計算して補正します。
- 他人の戦車と砲弾は約115ms遅れで、2つのスナップショットの間をつないで表示します（補間）。
- 切断すると20秒間は席を確保します。その間は自動で再接続し、同じタブで再読み込みしても同じ戦車で復帰します。満室（4人）のときは参加を断ります。
- 空になった部屋は30分後に削除されます。

### 素材の作り直し

```bash
pip install bpy==5.2.3                # Blender の Python モジュール（Python 3.13）
tools/build_assets.sh <arena.blend> <Tank3.blend>
```

見た目の部品だけ作り直すとき（.blend不要）：`tools/build_assets.sh --kit`。`tools/build_parts.py` が `tools/src/tank_base.glb` に砲塔7種・リア5種・サイド4種・輪郭線用メッシュ・柄用UVを追加します（部品はすべてこのスクリプトで作ったオリジナル）。`tools/render_kit.py` で組み合わせを画像に描けます。

ステージは4倍に拡大し（闘技場の床は約80m四方）、当たり判定用の高さマップ（0.5m間隔）を同時に作ります。戦車は車体と砲塔の2つに分け、砲塔だけを回転させます。

## 既知の制約

- ラグ補償（撃った時点の相手の位置で当たりを判定し直す処理）はありません。通信の遅れが大きいと、動いている相手に当てにくくなります。
- 照準の上下は砲身の角度として計算されますが、見た目では砲身が上下しません（砲塔が左右に回るだけ）。
- 戦車同士の押し合いはサーバー側だけで処理するため、ぶつかったとき自分の戦車が少し補正されることがあります。
- 通信量は1人あたり受信で毎秒十数KB程度です（スナップショットをJSONで毎秒30回送るため）。
- エフェクトは画質「低・中・高」で量が変わります（低：最大70個、中：150個、高：230個の粒）。実機での負荷は未計測です。
- iOS Safari は全画面表示と画面の向きの固定に対応していないため、縦向きのときは「横向きにしてください」と表示します。
- CPUは地形の高さマップだけを見て動くので、丘の向こうの敵の位置を正確に覚えているわけではなく、最後に見た場所へ向かいます。たまに壁際で少し迷います。
- 音の聞こえ方（音量バランス・音色）は数値と波形でしか確認しておらず、実際に耳では聞いていません。スマホのスピーカーで低音がどう聞こえるかも未確認です。
- レベルのデータは端末に保存した匿名IDに結びついています。ブラウザのデータを消すと（引き継ぎコードを発行していなければ）元に戻せません。
- 同じ人が2台の端末で招待部屋を作り、お互いを撃ち合えば経験値を稼げます（見た目にしか影響しないため、今は対策していません）。
- 経験値が入るのは試合が最後まで終わったときだけです。途中で退出したり、ニューゲームでやり直したりした試合は対象外です。
- PWA のインストールと全画面起動は、自動テスト（ヘッドレスChrome の判定）では合格していますが、Android・iPhone の実機ではまだ確認していません。
- 部屋の状態はメモリ上にあるため、Cloudflare 側で Durable Object が再起動されると、その部屋の試合はリセットされます。
